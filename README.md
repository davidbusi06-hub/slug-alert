# SlugAlert 

A personalized campus safety alert dashboard for UC Santa Cruz students.

## Live Site
[https://davidbusi06-hub.github.io/slug-alert](https://davidbusi06-hub.github.io/slug-alert)

## What It Does
SlugAlert gives UCSC students a personalized feed of campus incidents, safety alerts, and infrastructure updates — ranked by proximity to their college and matched to their alert preferences.

### Features
- 4-step onboarding that saves progress at every step
- 40+ UCSC campus locations to follow
- All 75 UCSC majors supported
- 8 alert categories (opt-out instead of opt-in)
- Severity filters: Critical, High, Medium, Low
- Dark / light mode
- Incomplete profile banner with quick-complete prompt
- Click-through alert detail modal
- Profile stored locally — no account needed

## How to Run Locally
1. Clone the repo:
   ```bash
   git clone https://github.com/davidbusi06-hub/slug-alert.git
   cd slug-alert
   ```
2. Open with Live Server in VS Code, or just double-click `index.html`

## Tech Stack
- Vanilla HTML, CSS, JavaScript
- No frameworks, no dependencies
- Hosted on GitHub Pages
